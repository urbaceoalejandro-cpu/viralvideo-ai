# ViralVideo AI 3.0 — Free/Gemini

Esta versión elimina OpenAI y ElevenLabs.

- Guion: Gemini API (con capa gratuita para modelos elegibles)
- Voz: espeak en el servidor, sin API de pago
- Video: FFmpeg
- Imágenes IA: no usa imágenes externas; crea fondos cinematográficos abstractos para mantener el flujo sin créditos de imagen.

## Render

Añade esta variable:

GEMINI_API_KEY = tu clave de Google AI Studio

Opcional:
GEMINI_MODEL = gemini-2.5-flash

No subas claves al repositorio.
